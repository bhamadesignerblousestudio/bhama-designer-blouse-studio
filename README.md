# Commerce Master Studio

Reusable premium commerce starter with BHAMA as the first reference implementation.

Open `index.html` for the current BHAMA frontend.
Read `MASTER_BLUEPRINT.md` before starting any new client site.
Edit `site-config.master.json` for the brand/contact/integration placeholders.

The long-term implementation is intentionally modular so the same master can be cloned for future
brands without rebuilding commerce, customer portal, CRM, ERP, production, payments and tracking
requirements from scratch.
